# Third-party notices

Feather Clipboard Manager contains no third-party source code. It is linked statically against the MinGW-w64 C/C++ runtime (libstdc++, libgcc, winpthreads; GCC Runtime Library Exception and permissive MinGW-w64 licences) and uses Windows APIs (GDI+, CNG/bcrypt, WinHTTP, Win32). The installer is built with NSIS (zlib/libpng-style licence). Optional OCR uses the Windows.Media.Ocr engine that is part of Windows.
