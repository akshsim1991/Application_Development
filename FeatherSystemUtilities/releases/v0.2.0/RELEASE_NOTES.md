# Feather System Utilities 0.2.0 (preview)
Windows 10/11 x64, portable single EXE, offline, no telemetry. Unsigned (SmartScreen will warn).
- Dark UI modelled on the original Startup/Services Manager: toolbar, filter dropdown, More menu, right-click menus, details/properties dialogs, status bar.
- Startup: Run/RunOnce (both views), Startup folders, scheduled tasks (sign-in/boot), Explorer add-ons. Enable/Disable, Delete (backup), Restore, Add (current user), Undo.
- Services: inventory, Start/Stop/Restart/Pause/Resume, Start type, dependency-aware batches, Properties (General/Configuration/Recovery/Dependencies).
- Multi-select with batch confirmation; every change journaled and verified by read-back.
Tested only under Wine (Linux) with synthetic data - NOT yet on real Windows. Not implemented: Start later, Profiles, Drivers, Kill process, remote machines.
VirusTotal/Search online open your browser only after you confirm.
