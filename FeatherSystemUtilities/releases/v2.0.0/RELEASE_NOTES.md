# Feather System Utilities 2.0.0
- FeatherSystemUtilities-Setup-2.0.0.exe: installer for 64-bit and 32-bit Windows 7 SP1, 8, 10, 11.
- FeatherSystemUtilities-x64.exe / -x86.exe: portable builds.
New: navy sidebar UI with a Scan button and card pages; Custom Clean with tick boxes, Recommended and Deep Scan; full program uninstaller (standard or silent) that finds and deletes leftovers; Windows Update cache cleanup; Large files, Duplicates (Recycle Bin or permanent delete) and Empty folders; automatic update check (like Feather PDF); Windows 7 support.
Verification: 41 unit checks pass; builds compile for the Windows 7 API level. The new UI and features were not run on Windows (test environment unavailable) - please test and send screenshots of anything wrong.
