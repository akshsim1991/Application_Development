Feather View 2.1.19
- Feather View now appears in the Windows "Open with" menu for pictures AND videos (MP4, MOV, MKV, AVI, WMV, WebM and more) and in Settings > Default apps. It registers itself for your user account at start-up, so installed copies get it by updating; no administrator rights needed

Feather View 2.1.18
- Mouse multi-select in the gallery: press on the gallery and drag a rectangle over thumbnails to select them (hold Ctrl or Shift to add to the current selection). Ctrl+click and Shift+click also work, plus the check boxes

Feather View 2.1.17
- "Set as Wallpaper" and "Print" in the bottom bar only show while a picture is open
- The folder path above the gallery is editable: click it, type or paste a path and press Enter (Esc cancels)
- Settings now use tabs (Appearance, General, Viewing, Video, Performance, Updates, More) instead of one long page
- New themes: AMOLED (pure black), Midnight blue, Forest green, Sepia and Glass (translucent, acrylic blur on Windows 11)
- Tab options in Settings: random tab colours, tab numbers, always-visible close button, playing icon, reopen tabs, keep video playing
- Sidebar: pin or unpin (unpinned = compact icon bar) and a Quick Access list with your Pictures, Videos, Downloads, Desktop, Documents and drives (from the Windows user profile)

Feather View 2.1.16
- Right-click menu on pictures, videos and thumbnails: open, rotate, flip, copy image or file, copy path, show in Explorer, favourite, wallpaper, print, compare, slideshow, select all, delete (Recycle Bin)
- The thumbnail strip can be resized (drag its top edge or Ctrl + mouse wheel) and so can the Details pane (drag its left edge); sizes are remembered

Feather View 2.1.15
- Updates: new Settings > Updates options "Download new versions automatically in the background" and "Install a downloaded version automatically when I close Feather View"; the update check retries on a hiccup and a downloaded update installs instantly
- Releases are now published in one step so the update check never meets a half-published release

Feather View 2.1.14
- Double-clicking a video now switches full screen on and off (also with the extended video engine), without pausing the video

Feather View 2.1.13
- Much faster video thumbnails: videos no longer queue behind pictures, Windows' own thumbnail cache is used first, and each generated preview is remembered on disk (LocalAppData\FeatherView\thumbs) so the second visit is instant

Feather View 2.1.12
- FIXED: rotate and flip no longer show "Something unexpected happened" (the picture transform was not frozen); the same fix also covers photos that carry a camera rotation flag

Feather View 2.1.11
- On narrow windows the Details panel hides itself so all toolbar buttons (delete, favourite, menu) stay visible; it returns when the window is wide again

Feather View 2.1.10
- Gallery multi-select like Explorer: Ctrl+click adds or removes a picture, Shift+click selects a range; Shift+arrows (and Shift+Home or End) extend the selection, Ctrl+arrows move without selecting, Ctrl+Space ticks the current picture, Ctrl+A selects all

Feather View 2.1.9
- NEW: Group by (... menu > Group by): None, Folder, File type, Date (year, month or day) and File size. Groups get a title with the number of files
- FIXED: video thumbnails now show the preview picture Windows makes for the video (with a play badge) instead of a blank "VIDEO" tile

Feather View 2.1.8
- Multi-select: a check box in the top-left corner of every thumbnail (thumbnail strip and gallery). Tick several files, then Delete moves them all to the Recycle Bin in one go. Ctrl+A selects all, Esc clears the selection; the status bar shows "N selected"

Feather View 2.1.7
- Settings > General: option to turn off the "delete this file?" question (files still go to the Recycle Bin)

Feather View 2.1.6
- Rotate left, rotate right, flip, copy and delete are now always in the toolbar, with colour-coded icons (amber rotate, purple flip, teal copy, red delete, gold favourite, green slideshow)

Feather View 2.1.5
- FIXED: GIF files showed "This file could not be opened" (the animation data was used from the wrong thread); animated GIFs open and play again

Feather View 2.1.4
- FIXED: clicking a point on the video seek bar now really jumps there and stays (before, the click only moved the marker and it snapped back)
- NEW: quiet-audio boost button ("Boost") in the video bar, and volume up to 300% (extended video engine) for videos and movies that are hardly audible
- Opening a drive or folder now shows pictures from ALL folders underneath (older saved settings are migrated)
- Menus (the ... menu, sub-menus, right-click menus) now follow the light/dark theme correctly
- Subtitles (SRT, VTT, ASS) and aspect ratio in the built-in video player
- Video seek bar fixes; full-screen video controls hide after N seconds (Settings)
- New app icon; smaller update downloads with the small installer
