# Application_Development

- `FileGlade-Mac/` — FileGlade for macOS (SwiftUI/AppKit). Build with `./build.sh`; prepare an update with `./release.sh`.
- `FileGlade-iOS/` — FileGlade for iPhone (Xcode project).
- `ClipboardManager/` — Feather Clipboard Manager for Windows (C++/Win32). Build with `scripts/make_installer.sh`; the installer is in `releases/`. See its README and `docs/REQUIREMENTS.md`.
